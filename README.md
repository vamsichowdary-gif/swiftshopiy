\# SwiftShop E-Commerce Platform



A modern full-stack e-commerce web application built with \*\*React (Vite)\*\* and \*\*Laravel (PHP)\*\*.



\## Features

\- \*\*Storefront\*\*: Browse products, product details, responsive navbar, and cart slide-over drawer.

\- \*\*Cart \& Checkout\*\*: Persistent cart, instant quantity updates, subtotal calculations, and checkout form.

\- \*\*Admin Workspace\*\*: Overview dashboard with real-time stats (revenue, order counts, status breakdown), order management with status workflow updates, and user lists.

\- \*\*Authentication\*\*: Token-based authentication using Laravel Sanctum with role-based middleware (`Customer`, `Admin`, `Super Admin`).



\## Tech Stack

\- \*\*Frontend\*\*: React 18, Vite, Tailwind CSS, Lucide Icons, Axios, React Router

\- \*\*Backend\*\*: Laravel 11, PostgreSQL / MySQL, Laravel Sanctum



\## Project Structure

\- `/frontend`: React client application

\- `/backend`: Laravel RESTful API
